# guess--my-number
Guess My Number - JavaScript Practice Project from Jonas Schmedtmann's course.


- About the project
- Guess My Number is a simple number-guessing game.
- the player tries to guess a secret number and receives feedback to help find the correct answer.

- Features
  .Guess a secret number
  .Receive feedback for each guess
  .Track the Player's score
  .Keep track of the nigh score
  .Restart the game and play again
